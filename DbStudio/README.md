# DB Studio · SQL Server 数据库设计工作台

.NET 10 + Blazor Interactive Server。设计、项目成员、审计和连接配置持久化到 SQLite，日常维护不依赖 Excel。

部署到 Windows IIS 请按 [IIS 部署与运维手册](docs/deployment.md) 操作，包含完整配置示例、现有数据迁移和升级回滚流程。

## 启动与账号

```powershell
dotnet run --project DbStudio --no-launch-profile --urls http://127.0.0.1:5188
```

首次账号 `admin`，随机密码位于 `App_Data/first-run.txt`。新安装创建空白项目；只有显式配置 `Studio:LoadLegacySeed=true` 才在空存储加载历史迁移资料，已有项目不会被覆盖。

密码使用 ASP.NET Core PasswordHasher。账号修改、停用或修改密码会撤销旧会话；角色和项目成员权限在服务入口实时读取。连续五次登录失败锁定十分钟，另有 IP 限流。

## 项目和设计

- 打开或刷新工作台默认进入项目首页，切换项目也进入该项目首页；地址中的 `project` 标识可保留刷新前选择的项目。左上角 DB Studio 图标或左侧“项目首页”随时返回，有未保存修改时先确认。
- 首页展示已保存设计的表、字段、模块（含空模块）、索引与唯一约束（不含主键）、表关系及检查约束数量；表关系统计同时区分逻辑关系和物理外键。首页还展示模块分布、当前项目最近 20 条活动（时间、操作人、动作和内容）。查找数据表统一使用左侧搜索；点击“刷新统计”更新项目快照和活动。首页不连接实际数据库，活动只在进入或刷新首页时按项目权限读取。
- 顶部或项目首页的 **ER 图** 打开整个项目的关系画布。物理外键显示为蓝绿色实线，逻辑关系显示为紫色虚线；默认仅展示有关联的表以及主键、关系字段。支持按模块、关系类型、表名或字段搜索，切换全部字段，滚轮缩放、拖动画布和一键适应；点击表卡片返回对应表设计。ER 图只读取已保存设计，不连接实际数据库。
- 顶部 **字段与引用快速检索** 为当前已保存项目修订建立内存索引，支持字段名、定义名、表名、模块、类型和备注的多词搜索，并显示同名字段数量、正向引用、反向引用及逻辑/物理类型。点击结果直接打开目标表、选中并定位字段；Ctrl+K 聚焦检索框。切换项目或修订变化时自动重建索引，无需独立搜索服务。
- **项目设置 → 基本信息**：修改项目名称和说明。
- **项目设置 → 模块管理**，或左侧 **新建 / 管理模块**：独立创建空模块、重命名模块；重命名同步更新模块内所有表。
- 左侧 **创建项目**：创建者自动成为新项目管理员。
- 按模块分组，搜索表名、业务名称或字段；字段逐行编辑、移动、删除，支持 Tab / Enter、Ctrl+S。
- 字段只通过顶部“新增字段”追加，底部不再提供“添加一行”。新增后清空字段筛选、选中新行并滚动聚焦字段名，批量粘贴定位到第一条新增字段。
- 备注在表格中保持单行，长内容省略显示；悬停或键盘聚焦可预览完整内容，保留换行并支持滚动、复制。点击备注或展开图标，在大文本框中编辑；取消不修改草稿，应用后点击“保存设计”生效。
- “保存设计”（含 Ctrl+S）先执行与“检查设计”相同的检查，失败时列出问题并保留草稿。当前表每个字段的定义名必填，纯空格也不通过；服务端保存同样校验，失败不增加版本。已有无定义名字段可读取，编辑保存时需要补齐。
- 字段勾选一行或多行后点“批量复制”，将带格式标识的字段定义写入系统剪贴板；切换目标表、项目或其他工作台页面后，点“批量粘贴”生成字段。浏览器无法直接读取时，在弹窗中 Ctrl+V 后点“生成字段”。复制需设计与导出权限，粘贴需目标项目设计权限。
- 粘贴保留类型、长度、精度、定义名、备注、默认表达式等字段属性，追加到表末尾并选中；同名自动添加后缀。主键、自增需在目标表设置，默认约束名称重新生成；计算表达式保留原文，需核对目标引用。操作只修改草稿，保存后生效。已移除旧 Excel 制表符批量粘贴入口。
- 字段可多选后批量上移、下移；连续选中行整组移动，不连续选中行分组移动，保留相对顺序和勾选。移动按完整字段列表处理，边界处不能继续移动的组保持原位；调整后点击“保存设计”。
- SQL Server 常用类型、长度、decimal 精度、小数秒/float 精度、默认表达式、排序规则、计算列、自增、复合主键。
- 索引支持唯一、聚集、升降序、包含列和过滤条件；表关系分为逻辑关系和物理外键，另支持 CHECK。
- 新增表关系默认是逻辑关系，只保存在设计、备份、分享和归档中，不生成 SQL，也不参与 DacFx 数据库比对与同步；切换为物理外键后才显示参照动作并生成数据库约束。旧项目中未记录关系类型的条目按物理外键处理。
- 逻辑关系仍检查两侧表、字段、数量及类型是否匹配，但允许目标字段不是数据库主键或唯一键；物理外键继续要求目标键唯一并校验删除、更新动作。数据库反推只读取物理外键，合并时保留已有逻辑关系；若实际库出现同名或同端点物理外键，则在预览中显示关系类型变化。
- 复制完整表结构，重建 ID 和约束名称，重映射自引用，并保留逻辑/物理关系类型；独立检查设计与入站表关系。
- 每张表可设置“业务数据、基础数据、系统数据、日志审计、临时 / 缓存”用途标签；旧项目安全归入“未分类”。标签随项目备份、复制表和数据库反推合并保留。
- 编辑草稿与已保存文档分离；版本条件更新和事务保护他人修改。
- 无变化的重复保存不升级版本，也不写入变更审计；字段顺序、结构、业务说明或备注等设计内容实际改变时才增加修订号。过期客户端仍须刷新后重试。
- 每个实际保存的 `r` 修订会保留完整项目快照。顶部 **版本** 可查看任意历史修订到当前的表、字段、索引和关系差异，项目管理员可恢复整个项目；表的 **变更记录** 可只恢复当前表。恢复会创建新 `r`，不改写历史。
- `V` 是已发布设计快照。数据库连接明确划分为开发、测试、预发布、生产四级环境：开发环境可从当前 `r` 建立或复用 `V`，其他环境只能选择不可变 `V`；所有已配置的较低环境必须先完整验证同一个 `V`，才能继续向上推进。每个连接保留最后成功同步的 `r / V`、范围和最新执行状态，顶部版本页显示环境矩阵。

## 项目隔离

全局角色和项目成员权限共同生效。系统管理员显式管理所有项目；其他账号默认不能访问项目，必须在 **项目设置 → 项目成员** 按已有登录账号添加。

| 项目角色 | 能力上限 |
| --- | --- |
| 只读成员 | 查看本项目 |
| 设计成员 | 查看、设计、导出 |
| 数据库维护成员 | 设计成员权限，加数据库工具 |
| 项目管理员 | 项目信息、成员、分享、连接和全部项目功能 |

全局只读账号即使分配为项目设计成员，也不能保存表。历史项目升级后默认仅系统管理员可见，应重新添加成员。

查询、保存、导出、审计、成员、连接、反推、比对、执行均检查项目归属。备份恢复为新项目时不复制成员、分享或数据库凭证。

## SQL Server 工具

入口：**数据库工具 → 连接、反推与结构同步**。

1. 保存并测试连接，同时指定开发、测试、预发布或生产环境。Windows 认证使用应用服务器运行账号，SQL 认证密码加密保存、不回显，不进入项目备份或分享。必须指定已有业务数据库，不接受系统库。
2. **读取结构并预览**：读取表、字段、主键、索引、外键、CHECK 和说明，不读取业务数据。需要目标数据库的 `VIEW DEFINITION` 权限。
3. **确认合并到设计**：同名表更新结构，保留原 ID、模块和业务说明；新表加入项目，设计独有表保留。无法无损映射的特性会阻止合并并显示原因。
4. **开始比对**：开发环境可选择当前 `r` 或已有 `V`；测试、预发布和生产只能选择已有 `V`。微软 DacFx 根据对应不可变快照和实际库生成差异报告及 SQL。
   警告按中文分类展示，保留具体原因、字段与类型变化，按问题编号关联受影响对象；可展开原始诊断 XML 核对。未知诊断仍保留原文，不省略风险提示。
5. **执行同步**：勾选已核对脚本并输入完整数据库名。高风险 DDL 还必须输入与目标库绑定的数据损失确认短语；生产环境另外要输入包含目标 V 的发布确认短语。服务端重新检查环境顺序、不可变快照、成员、连接版本和目标结构；计划十五分钟有效，过期、修改或重复执行都会要求重新比对。即使数据库已经没有差异，也必须重新完整验证后才登记该环境版本。
6. **数据清空**：整库工具可按数据分类筛选已保存表，单表比对页可只选当前表。连接实际库核对表和外键后生成可预览、可下载的事务 `TRUNCATE TABLE` SQL，也可输入完整库名直接执行。脚本使用最小日志的 TRUNCATE，绝不静默退回逐行 DELETE；范围外表引用所选父表时拒绝计划，范围内跨表外键在同一事务中删除后按列顺序、参照动作及原启用/信任状态重建，自增列由 TRUNCATE 自动复位。清空只删数据、不删结构，执行前必须逐表核对并备份。

默认保留实际库的多余对象并阻止可能的数据丢失。删表、删列、字段容量收窄和 DacFx 数据兼容性诊断会生成结构化高风险清单。显式启用删除、解锁高风险 DDL 并完成专项确认后，DacFx 可执行表重建等可能损失数据的更新。解锁只取消预防性阻断：现有值无法转换或不满足新约束时，SQL Server 仍会使事务失败，不会暗中生成默认值或强制截断。DacFx 负责依赖验证与事务部署，执行成功/失败写入项目审计。部署期间避免其他工具同时改目标结构；执行取消或失败后重新比对确认实际状态。

误加空列的删除：先在设计中删除并保存，进入单表比对，重新比对并核对实际脚本。DacFx 即使未开启“删除多余对象”，也可能以“修改表”的形式生成删列，因此空列核验依据实际模型差异，不依赖该选项。整份计划仅删除普通列（可含其说明）、且实际列全部为 `NULL` 时，显示“删除全空列，自动放行”，无需勾选允许数据丢失。此专用路径在同一事务内用排他表锁重新检查所有待删列后执行删除，出错全部回滚。空字符串、空格和 `0` 都算数据，不自动放行；存在其他变更、依赖约束、行安全策略或无法完整核验权限时，仍使用常规风险保护，并在“空列删除未自动放行”中显示具体原因。

类型变更会自动核验容量：例如 `varchar(100) → nvarchar(100)`、`varchar(30) → nvarchar(50)`、可变长度字段加长、整数范围扩大，以及同时保留整数位和小数位容量的 decimal 扩展。整份计划仅有这些扩展及说明变更时，显示“容量扩展，自动放行”，无需勾选允许丢失数据。执行前仍按最新目标结构复核，并由 SQL Server 检查索引和约束。

缩短长度、缩小数值范围或降低小数位，会逐列提示可能截断、舍入或溢出，默认保留保护；这不表示现有数据一定越界。Unicode 转非 Unicode、`varchar(max) → nvarchar(max)` 等无法仅凭类型证明安全的转换不自动放行。扩容与删列、其他结构调整混在同一计划时，也不会一并解除保护。项目比较的默认排序规则沿用目标库，不修改数据库排序规则。

连接栏支持刷新和删除配置。修改连接所属环境会使旧环境下的版本状态失效，必须重新比对验证；更改环境、服务器、数据库或账号也会使旧同步计划失效。删除仅移除保存的连接和凭证，不操作实际数据库。数据库维护成员可以使用连接，只有项目管理员能修改或删除配置。测试、预发布和生产不允许绕过 V 执行当前设计或单表结构同步。

编辑模型针对关系表结构，不覆盖整个 SQL Server 引擎：内存优化、时态、分区、用户定义类型、FILESTREAM、空间/全文/列存索引、禁用或未信任约束等无法无损反推时会提示。过程、视图、账号不在设计器维护范围，不会仅因未出现在设计中而删除。

## 免登录只读分享

**项目设置 → 只读分享** 创建链接，支持 7/30/90 天或长期有效，并可撤销。创建需要项目管理、项目导出和全局导出权限。

分享展示单个项目最新保存的结构，支持搜索、表格/卡片切换和表关系跳转，并明确标识逻辑关系或物理外键。匿名页面独立于编辑工作台，没有写接口。随机令牌仅保存 SHA-256 摘要；每次请求检查有效期和撤销状态，响应使用 `no-store`、`no-referrer` 与禁止索引标头。已被访问者保存的内容无法通过撤销收回。

`127.0.0.1` 链接只能本机访问。对外访问需实际部署并配置 `Studio:PublicBaseUrl`，详见 [部署说明](docs/deployment.md)。仅填写域名不会自动建立外部访问。

## 备份和迁移

### 数据库结构 PDF 归档

**备份与导入 → 结构归档（PDF）**：填写文档编号、版本、数据库名称、环境、编制人等信息，生成并下载当前项目全部已保存表的 A4 横版归档文件。字段表按“字段名、中文名、类型、空值、默认/生成、主键、关系、说明”排列；关系栏以实心圆表示物理外键、空心圆表示逻辑关系，索引作为表级结构独立排列在字段表下方。未保存草稿不在导出范围；若项目被其他会话更新，需刷新后重试。

- 首页记录文档信息、项目修订、导出时间及归档范围；文档只包含归档说明、可见目录和表结构正文，不附加核验、附件登记或审批签字页。
- 首页后提供带正文页码的可见目录，物理英文表名与中文业务名成对显示；正文按模块顺序紧凑排列，多张小表共用一页，长表续页重复中英文表名和表头，并保留 PDF 书签。
- 空值限制栏可空留白、不可空写中文；保留自增、计算表达式、精度、主键、索引、外键、检查约束及设计备注。计算列不推测数据库推导类型与空值性。
- 服务端再次验证全局和项目导出权限，使用已保存设计生成，不连接实际数据库；未纳入设计器的视图、过程等对象不在归档范围。SQL、JSON 等附件需另行导出登记。
- 使用 PDFsharp 6.2.4 和内嵌中文字体，服务器无须安装浏览器或 Office；字体授权见 `Assets/Fonts/OFL.txt`。

**备份与导入** 支持项目 SQL 下载、项目 JSON 导出与恢复。项目 SQL 导出全部已保存表，先创建 schema 和所有表及索引，再统一创建物理外键；逻辑关系不会进入 SQL。不受当前选中表或搜索过滤影响，也不执行数据库变更。未保存修改不在项目导出范围内，当前表编辑内容仍可在 **SQL 预览** 中单独下载。JSON 恢复先预览，再创建独立项目，重建项目/表/字段 ID 和表关系；始终不覆盖原项目。最大 10 MB、500 张表、10000 个字段。

项目 JSON 只含设计，不含账号、成员、分享或连接。完整服务器备份应停止应用后复制 `App_Data`，或使用 SQLite 正规在线备份并单独备份密钥。可用 `Studio:DataDirectory` 配置外置目录。数据、密钥、首次密码、bin/obj 和日志不应提交 SVN/Git。

## 验证

```powershell
dotnet format CompanyTools.slnx --verify-no-changes --no-restore
dotnet run --project DbStudio.Checks
```

真实 SQL Server 集成检查使用专用测试实例，只操作自己创建的 `DbStudioIntegration_随机值` 等数据库，包含建表、反推、增量同步、数据保留、过期计划、目标漂移、默认数据丢失保护、显式删表、字段收窄成功与不兼容数据回滚。

```powershell
$env:STUDIO_SQLTEST_SERVER='(localdb)\DbStudioGoalTests'
dotnet run --project DbStudio.Checks
```

测试库保留供复查，命令输出完整名称。结构校验和测试不能替代在实际目标环境预览脚本、检查依赖并备份。
